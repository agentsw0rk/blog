# LinkedIn Teaser: Warum AI Spec Driven Development braucht

AI kann heute sehr schnell Code schreiben.

Genau deshalb wird diese Frage wichtiger:

Woher weiss die AI eigentlich, was richtig ist?

Prompts reichen fuer kleine Aufgaben. Bei Fachlogik, Randfaellen und
langfristiger Wartung braucht ein Agent mehr:

eine Spec.

Spec Driven Development wird durch AI nicht weniger wichtig. Es wird wichtiger.
Wenn Code schneller entsteht, muss Absicht frueher klar sein.
