Markdown ist für technische Blogs ein guter Standard, weil der Inhalt lesbar bleibt, auch wenn keine Website gebaut wird.

## Vorteile

- Änderungen sind in Git diffs sichtbar.
- Beiträge lassen sich ohne CMS bearbeiten.
- Front matter hält Metadaten nah am Text.

Das HTML ist nur das Build-Ergebnis. Die Quelle bleibt bewusst einfach.
