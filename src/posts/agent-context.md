Ein Agent arbeitet besser, wenn Projektdetails nicht nur im Chat stehen. Kurze Markdown-Notizen machen Entscheidungen auffindbar und reduzieren Wiederholungen.

## Was dokumentiert wird

- Welche Annahme getroffen wurde.
- Welche Alternative verworfen wurde.
- Welche Datei oder Pipeline dadurch wichtig wurde.

## Ergebnis

Der Blog wird zum technischen Speicher: knapp, versioniert und direkt neben dem Code.
